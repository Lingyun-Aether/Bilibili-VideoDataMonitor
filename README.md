A simple tool/crawler for monitoring real-time video data on Bilibili, only aim to entertainment for individual.
Users can obtain various data including plays, likes, coins, shares, comments and online count... and their visual graphs of variation, change rate, and absolute value(+trend line).
Support to import or export .csv or .jsonl files, and to automatically save.
This tool includes AI-generated code.

这是一个简陋的b站视频数据小爬虫，仅供本人个人娱乐使用，只是把github当个云盘而已。
主要功能即实时获取视频的各项数据，包括点赞收藏投币评论等等。可视化图表有三种显示模式：绝对值、变化量、变化率，且有趋势线（EMA、SMA与线性回归）功能。
能导入或导出csv或jsonl文件，也有在爬取过程中的自动保存功能。
部分代码由AI生成。
